# Sorgenti del libro

Inserire qui, quando pronti, i sorgenti LaTeX e le immagini autorizzate.
Nessun materiale del vecchio libro e' stato copiato in questa cartella.

La configurazione iniziale riprende il vecchio progetto: main.tex con LuaLaTeX.
Il percorso e il motore sono modificabili in ../config/book.json.

L'inserimento dei sorgenti non abilita la pubblicazione: e' necessario il
via libera descritto in ../maintenance/PUBBLICAZIONE.md.

Attenzione: questo repository e' pubblico. I sorgenti inviati a GitHub diventano
visibili anche quando la pubblicazione dei PDF e' disabilitata.
